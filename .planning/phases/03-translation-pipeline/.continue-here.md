## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Parsing `claude -p` stderr | The CLI prints permission-rule warnings on stderr; mixing streams corrupts the JSON parse | advisory | callClaude helpers read stdout only; never `2>&1` a pipeline call |
| Running `npm run build` locally | The package script chains `prisma migrate deploy` and the Prisma CLI reads `.env` = the production DB | advisory | Standing STATE.md rule; local build gate is `npx next build` |
| Trusting the dry-run token estimate | The estimator is ~8x low on input and ~12x low on output (assumes one call, ignores cache creation/read the CLI reports as input); measured 230,296/127,891 vs estimated 27,592/10,396 on the proof post | advisory | Recalibrate before the Phase 5 backlog sweep; do not use the dry run as the size brake |
| Believing the harness "stopped" report for a running sweep | 03-09: the harness reported the backlog sweep stopped while it was still writing; a resume run was started concurrently and the count re-query assertion aborted it correctly | advisory | Before resuming a translate run, check the run-state artifact mtime and TokenUsage rather than the harness signal |
